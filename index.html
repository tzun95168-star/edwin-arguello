Fashion Style — Ecosistema Omnicanal E-Commerce, POS, Producción & Móvil

Proyecto integral de software en el que estoy trabajando actualmente para gestionar la operación de una empresa de confección y tienda de ropa: escaparate virtual, punto de venta físico (POS), producción por lista de materiales (BOM), inventario/kárdex, facturación, pagos con Wompi y aplicación móvil Android conectados en tiempo real.

Frontend Reactivo en Vue 3 + Vite + Tailwind CSS

Interfaz web en construcción e iteración continua con doble entorno: escaparate e-commerce para clientes y panel administrativo con control de acceso por roles (Administrador, Empleado, Cliente).

  • E-Commerce funcional: Catálogo con filtros, variantes por talla/color, favoritos, reseñas, carrito persistente (Pinia) y autocompletado geográfico de municipios de Colombia.
  • Dashboard & Analítica: KPIs en tiempo real, gráficas de ventas (POS vs Online), control de gastos y medios de pago con Chart.js + exportación a Excel y PDF.
  • POS Físico & Producción Textil: Venta rápida en mostrador con cálculo de cambio y calculadora de órdenes de producción y costeo por lote (BOM).
  • Tiempo Real sin Recarga: Cliente Laravel Echo + composable useRecargaAutomatica para refrescar vistas automáticamente ante pedidos o pagos.
Vue 3 JavaScript ES6+ Vite Pinia Tailwind CSS Bootstrap Axios Chart.js
Clic para ampliar · Dashboard Administrativo (Vue 3 + Chart.js)

API REST en Laravel 12/13 + WebSockets + Wompi

Núcleo transaccional en PHP 8.3 en el que trabajo sobre arquitectura de servicios, seguridad basada en roles y sincronización bidireccional en tiempo real.

  • Seguridad y Autenticación: Laravel Sanctum, inicio de sesión con Google OAuth 2.0, verificación 2FA por OTP de 6 dígitos y permisos granulares con Spatie RBAC.
  • Pasarela Wompi Bancolombia: Integración de pagos con PSE, Nequi, DaviPlata, tarjetas y webhooks con envío y descarga de factura.
  • Reserva Transaccional de Stock: Bloqueo temporal de inventario en checkout con expiración y liberación automatizada.
  • Laravel Reverb & Contenedores: Eventos en tiempo real vía WebSockets y configuración Docker para despliegue.
PHP 8.3 Laravel 12/13 Sanctum Laravel Reverb Spatie RBAC Google OAuth Wompi API Docker
Clic para ampliar · Checkout Integrado con Wompi Bancolombia

Aplicación Móvil Android en Flutter 3 + Dart

Extensión móvil nativa en desarrollo conectada a la misma API REST en Laravel, permitiendo comprar desde el celular y operar módulos administrativos en movilidad.

  • Arquitectura Modular: Estado reactivo con Flutter Riverpod, navegación separada para cliente y administrador con GoRouter y cliente HTTP Dio.
  • Checkout Móvil & Deep Links: Flujo de compra integrado con Wompi, seguimiento de estado de pedidos y descarga de comprobantes.
  • POS Móvil & Recibo Térmico: Ventas desde dispositivo móvil y generación de recibos térmicos de 80mm en PDF.
  • Gestión Operativa: Consulta de bitácoras, control de kárdex, gestión de prendas, órdenes de producción y compilación de instaladores APK.
Dart 3 Flutter 3 Riverpod GoRouter Dio WebSockets PDF / Printing APK Android
